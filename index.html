Security & assurance

Current mode: Local demonstration only. There is no AI model call, no PDF parser, no login, no server-side validation and no automatic legal verification.

Data: Pasted text is processed by JavaScript in this browser. Knowledge and feedback are stored locally on this device; local storage is not an encrypted government records system. Do not enter sensitive official records.

Production design: Authenticated backend, organisation-scoped retrieval, approved AI model gateway, server-side audit logging, validated rules and explicit human decision authority.

Deployment: GitHub Pages is public hosting. Never place API keys or government records in this repository.

Knowledge library

Locally saved, manually declared entries. A verified checkbox does not authenticate a document. Official source documents and effective dates must be independently checked.
